# Offline Vazirmatn font

`Vazirmatn.woff2` is an unmodified copy of the official Vazirmatn variable webfont, renamed only at the filesystem level. It includes Persian/Arabic and Latin glyphs, normal style, and a continuous `wght` axis from 100 to 900 (default 400).
